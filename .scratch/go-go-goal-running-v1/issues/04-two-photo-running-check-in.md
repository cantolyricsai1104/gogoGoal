# 04 — 以雙相片完成每日 Running 打卡

**What to build:** 讓使用者在預定跑步日以兩張相片完成私人自我打卡。系統以帳戶主時區嚴格執行同一曆日、至少 15 分鐘間隔與 23:45 首次上傳截止；每張相片可在明確同意後取得 Gemini 的正向簡短鼓勵，但 AI 結果不影響完成判定。

**Blocked by:** 02 — 建立安全的 Running 草案並正式承諾。

**Status:** ready-for-agent

- [ ] 只有進行中目標的預定跑步日可開始當日打卡。
- [ ] 第一張相片上傳成功後保存媒體及可信時間戳，並顯示第二張尚需等待的時間。
- [ ] 帳戶主時區 23:45 後不能開始當天第一張相片打卡。
- [ ] 未滿 15 分鐘上傳第二張時，系統拒絕完成並顯示剩餘等待時間。
- [ ] 第二張相片跨越帳戶主時區的午夜時，系統拒絕將其計入前一日完成。
- [ ] 同一曆日內相隔至少 15 分鐘的第二張相片會把當日紀錄標示為完成。
- [ ] UI 清楚說明相片是自我打卡，不會用來判斷使用者是否真的跑步。
- [ ] 首次啟用相片鼓勵前，系統說明相片會傳送給 Gemini 並取得明確同意；設定中可隨時關閉。
- [ ] 每張相片均取得正向、簡短的運動鼓勵；回應不得推測身分、年齡、性別、體型、健康、情緒或評論其他入鏡者。
- [ ] 未同意影像分析或 Gemini 失敗時，打卡仍成功並使用預設鼓勵文字，不要求重新上傳。
- [ ] 第二張相片完成後顯示明確的當日完成狀態，並在重開 App 後正確還原。
- [ ] 測試覆蓋第一張、等待中、未滿 15 分鐘、23:45 截止、跨日、正常完成、未同意分析及 Gemini fallback。
