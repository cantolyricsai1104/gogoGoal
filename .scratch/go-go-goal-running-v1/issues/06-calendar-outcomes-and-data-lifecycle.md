# 06 — 完成 Workspace 日曆、達標結算與資料生命週期

**What to build:** 完成 V1 的長期回顧與資料治理。使用者可在 Workspace 日曆及時間軸查看每日完成、缺席與補救結果；週期結束由系統計算達標率。相片與帳戶資料依已承諾的保存及刪除規則處理。

**Blocked by:** 03 — 在 Workspace 管理 Running 承諾生命週期；04 — 以雙相片完成每日 Running 打卡；05 — 安排嚴肅提醒並處理每日缺席。

**Status:** ready-for-agent

- [ ] Workspace 日曆顯示預定跑步日及其待完成、完成、缺席或跳過狀態。
- [ ] 目標時間軸顯示承諾、版本調整、相片打卡、完成、缺席、補救、暫停、恢復、完成及放棄事件。
- [ ] 日曆與時間軸不公開、不分享，且只能由目標擁有者查看。
- [ ] 週期結束以完成跑步日除以預定跑步日計算達標率，並顯示計算依據。
- [ ] 達到承諾門檻時可完成及歸檔；未達標時只能延長週期、建立下一週調整或放棄並填原因。
- [ ] 原始相片上傳 90 天後自動刪除，但完成、缺席、跳過原因及時間軸文字紀錄保留。
- [ ] 使用者可提早刪除個別相片，且刪除不會改寫已完成的文字狀態。
- [ ] 帳戶刪除先進入 30 天可撤銷期；期間可取消刪除並恢復正常使用。
- [ ] 30 天期限結束後刪除帳戶的可識別資料、相片、目標及紀錄，只可保留不可回推個人的聚合統計。
- [ ] 清理或刪除作業失敗時可安全重試，不會將部分刪除顯示成已完成。
- [ ] 測試覆蓋日曆狀態、達標與未達標結算、90 天相片清理、個別相片刪除、帳戶撤銷期、取消刪除及最終清除。
- [ ] 完整互動測試驗證登入、建立並承諾 Running 計畫、雙相片完成、缺席補救、生命週期操作及 Workspace 回顧的 V1 主流程。
