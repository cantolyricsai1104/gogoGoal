# 02 — 建立安全的 Running 草案並正式承諾

**What to build:** 讓登入使用者在 Keep Fit／Running 中完成必要背景資料與健康安全篩查，取得可修改的 Gemini 跑步計畫草案，並透過明確的「我承諾這個計畫」動作建立唯一一個進行中的 Running 目標。

**Blocked by:** 01 — 建立 Go Go Goal 私人 Workspace 與 Running 工作流骨架。

**Status:** ready-for-agent

- [ ] 規劃流程收集年齡區間、近四週運動／跑步習慣、可跑日子、每次可用時間、期望能力及受傷／健康限制。
- [ ] 體重、身形相片及精確住址均不列為必填資料。
- [ ] 安全篩查遇到胸痛、暈眩、已知心肺或關節問題、醫生限制運動等警示時，不產生自行訓練處方，並清楚建議先諮詢專業人士。
- [ ] 沒有安全警示的初學者會取得保守的跑走交替草案。
- [ ] Gemini 只產生可編輯的計畫草案；模型錯誤、超時或不可用時提供可理解的重試或安全 fallback，不建立隱性承諾。
- [ ] 草案顯示每週跑步日、每次建議時長、週期及達標率，且使用者可在承諾前修改。
- [ ] 只有使用者按下「我承諾這個計畫」後，目標才轉為進行中並安排每日紀錄。
- [ ] 每位使用者同時只能有一個進行中的 Running 目標；第二個承諾會被拒絕並引導回現有目標。
- [ ] 正式承諾保存計畫版本、主時區、承諾時間、週期、達標率及預定跑步日期。
- [ ] 測試覆蓋安全警示、正常草案、草案修改、未承諾草案、明確承諾及重複進行中目標被拒絕。
