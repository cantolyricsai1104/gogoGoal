# 05 — 安排嚴肅提醒並處理每日缺席

**What to build:** 依帳戶主時區為預定跑步日安排兩次推播，並在午夜確定性結算缺席。未完成使用者翌日必須面對原始缺席，選擇補登、跳過並說明原因或重新安排，而不是悄悄刪除紀錄。

**Blocked by:** 04 — 以雙相片完成每日 Running 打卡。

**Status:** ready-for-agent

- [ ] 正式承諾後，系統依帳戶主時區為每個跑步日安排 10:00「今日有跑步承諾」通知。
- [ ] 同一跑步日 20:00 安排最後一次直接、嚴肅但不羞辱的提醒。
- [ ] 每天最多發送上述兩次 Running 提醒，不持續轟炸使用者。
- [ ] 通知文字不可羞辱、威脅或對人格作判斷，並要求使用者採取明確下一步。
- [ ] 使用者拒絕推播權限時仍可承諾，但在確認前會看見缺少提醒的影響及前往系統設定的入口。
- [ ] 拒絕或關閉推播不會停用午夜結算、Workspace 任務或缺席紀錄。
- [ ] 帳戶主時區午夜仍未完成雙相片打卡時，當日紀錄自動標示缺席。
- [ ] 翌日向缺席使用者提供補登、跳過並填原因或重新安排的處理流程。
- [ ] 補救選擇以新事件附加到時間軸，原始缺席事件不可被覆寫或刪除。
- [ ] 使用者更改帳戶主時區時，未來提醒與截止會重新計算；裝置自動時區變更本身不改寫既有結果。
- [ ] 測試覆蓋通知已允許、拒絕、重新啟用、正常完成後不結算缺席、午夜缺席、翌日補救及跨時區行為。
