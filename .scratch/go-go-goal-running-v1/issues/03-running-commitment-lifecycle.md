# 03 — 在 Workspace 管理 Running 承諾生命週期

**What to build:** 讓使用者在 Workspace 檢視及管理正式 Running 承諾。目標不可直接刪除；使用者可修改下一週計畫、暫停、恢復、完成或放棄，所有原因、版本及狀態改變均保留在私人時間軸。

**Blocked by:** 02 — 建立安全的 Running 草案並正式承諾。

**Status:** ready-for-agent

- [ ] Workspace 清楚區分草案、進行中、暫停、完成及放棄的 Running 目標。
- [ ] 已承諾目標沒有直接刪除入口，只能完成、放棄或暫停。
- [ ] 修改每週跑步日、時長或難度時必須填寫原因，且新版本從下一週開始生效。
- [ ] 舊計畫版本、修改原因、生效日期及變更者保留為只讀歷史。
- [ ] 暫停目標時必須填原因及恢復日期，單次暫停不可超過 30 天。
- [ ] 暫停到期時要求使用者恢復、再次延長並填原因，或放棄歸檔。
- [ ] 放棄目標時必須填原因，並將目標及歷史移至歸檔區。
- [ ] 只有達到既定週期與達標率的目標可標記完成；未達標時完成動作被拒絕並顯示可行下一步。
- [ ] 每個狀態轉移及原因均顯示在 Workspace 的目標時間軸。
- [ ] 測試覆蓋非法狀態轉移、下一週才生效、30 天暫停上限、恢復、延長、放棄及達標完成。
